## Reemplazar la foto de Deyanires

1. Guardar la foto real (vertical, mínimo 720×900) como `public/images/deyanires.jpg`.
2. Guardar un recorte cuadrado pequeño (132×132) como `public/images/deyanires-sm.jpg` (se usa en el popup de WhatsApp).
3. `npm run build`.

La persona de la foto provisional es una modelo de banco de imágenes, no es Deyanires.
